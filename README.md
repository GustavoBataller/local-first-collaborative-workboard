# Local-first Collaborative Workboard

A public, portfolio-ready collaborative workboard exploring a real local-first Product problem: users can continue supported work offline, preserve local intent, reconnect, synchronize safely, collaborate across independent clients, resolve material conflicts and recover without silent loss.

## Product principle

The Workboard is the Product.

Architecture, technology and engineering techniques must be chosen to serve the Workboard's requirements and evidence needs. They must not be added to exercise Anvil, create study evidence or make the implementation appear more sophisticated.
